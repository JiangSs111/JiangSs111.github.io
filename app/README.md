# Python 符号图谱（Python Syntax Atlas）

一个分层下钻式的 Python 基础符号与语法知识网站：首页为主目录，点击板块标题进入子目录，逐层下钻到具体知识点；每个符号配有含义说明、示例代码与可一键复制的实战示例，并嵌入各板块的思维导图。

## 功能特性

- **分层目录导航**：主目录（8 大板块）→ 子目录（30 个专题）→ 知识点详情，支持无限层级扩展
- **目录树侧栏**：随当前位置自动展开并高亮，面包屑随时返回上级
- **实战示例**：30 段可直接运行的 Python 示例，终端风格代码面板（行号、语法高亮、一键复制）
- **思维导图**：每个板块配有高分辨率思维导图，点击可全屏放大
- **Hash 路由**：每个层级页面均可收藏与分享
- **纯静态站点**：无后端依赖，可部署到任意静态托管平台

## 技术栈

- React 18 + TypeScript + Vite
- Tailwind CSS
- 数据驱动的知识树（`src/data/knowledge.ts` + `src/data/examples.ts`）

## 本地开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
# 产物输出到 dist/，可直接部署
```

## 内容维护

知识点与示例均为数据文件，修改后重新构建即可：

- `src/data/knowledge.ts`：知识树结构（板块、子目录、知识点条目）
- `src/data/examples.ts`：各叶子板块的实战示例代码
- `public/maps/`：各板块思维导图图片
